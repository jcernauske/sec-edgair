## Decisions Made
1. **Timestamp parsing in promote.py** — Timestamps stored as ISO strings in staging JSON need to be parsed back to datetime objects before writing to Iceberg. Used `datetime.fromisoformat()` via a `_parse_ts` helper.
2. **Only archive staging when no pending remain** — Initial implementation archived after any promote, which would lose pending proposals during partial approvals. Fixed to check for remaining pending proposals before archiving.
3. **resolve_entities_from_records for testability** — Created a separate function that takes raw dicts instead of reading from Iceberg, enabling all resolution tests to run without Iceberg infrastructure.

## Problems Encountered
1. **ArrowTypeError on timestamp fields** — First test run hit `object of type <class 'str'> cannot be converted to int` because `append_data` in iceberg_setup.py has special handling for DateType but not TimestamptzType. Timestamps came out of JSON as strings but PyArrow needed datetime objects. Fixed by adding `_parse_ts()` in promote.py.
2. **Staging file archived during partial approval** — `test_cli_approve_specific` failed because the staging file was archived after promoting ER-001, making ER-002 unreachable. Fixed by only archiving when no pending proposals remain.
