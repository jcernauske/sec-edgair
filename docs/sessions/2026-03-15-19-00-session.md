## Decisions Made
- Used `sys.exit()` instead of exceptions for kill switch — can't be accidentally caught/swallowed
- Reconciler is a separate module from the monkey (`chaos_reconciler.py` vs `chaos_monkey/`) — different trust boundaries
- Shadow zone uses full Iceberg table copy + append pattern (same as existing `iceberg_setup.py` utilities)
- Seed parameter for reproducibility — same seed = same corruptions, useful for regression
- Minimum 5 corruptions per dimension regardless of injection rate — guarantees coverage even at low rates
