## Decisions Made
- **Two-repo split over monorepo**: Framework repo (`edgair`) + domain pack repo (`edgair-sec-edgar`) rather than a monorepo with packages. Cleaner separation, domain packs are truly independent.
- **Domain manifest is for data ACQUISITION only, not domain semantics**: The manifest tells the framework how to get data (endpoints, auth, rate limits, schema). It does NOT pre-define what the data means. Domain understanding is discovered through EDA.
- **EDA-first discovery principle**: The data analyst runs BLIND — no domain context. The EDA report becomes the source of truth for domain discovery. Business terms, models, and DQ thresholds emerge from data, not from domain expertise.
- **Three-tier glossary hierarchy**: Tier 1 (standards like XBRL, HL7-FHIR — read-only, auto-approved), Tier 2 (domain glossaries like "finance", "healthcare" — community-curated, auto-approved), Tier 3 (project-specific — human approval required). Projects inherit from shared glossaries instead of every project reinventing terms. Data steward becomes a LINKER first, CREATOR second.
- **Hints as optional accelerators**: Domain packs CAN provide glossary seeds, concept mappings, metrics, etc. as "hints" — but these skip discovery steps, they don't replace them. A domain pack with zero hints still works, it just asks more questions.
- **Option C for concept mappings**: Hybrid approach — EDA discovers the taxonomy structure, then concept mapping is a separate human-assisted step after EDA but before base zone modeling. Mappings are an accelerator, not a prerequisite.
- **Build abstractions in-place first (Phase 1), split repos last (Phase 4)**: Reduces risk of breaking the SEC pipeline during refactor. All DQ scorecards must still pass before the split.
- **Keep the name "edgair"**: Already works without "SEC" prefix — reads as "edge + AI + rules." Domain-agnostic by accident.
- **BaseIngestor ABC pattern**: Domain packs implement `fetch()` and `flatten()`. Framework handles Iceberg writes, dedup, lineage, DQ gating. Clean separation of domain logic from infrastructure.
- **Amendment analysis becomes a domain-pack custom module**: Not generic enough for the framework. Domain packs get a `custom-modules/` escape hatch.
