## Decisions Made
- **Dark mode default with localStorage persistence** — Data people live in dark mode. Theme persists across page loads via localStorage. Light mode available via toggle button in nav.
- **System font stack throughout** — No web fonts at all. Zero FOUT, zero external requests for fonts. The system stack (-apple-system, BlinkMacSystemFont, Segoe UI, etc.) looks professional on every OS.
- **CSS custom properties for theming** — All colors defined as CSS variables on `[data-theme]` selectors. Toggle switches the data-theme attribute. No JS-heavy class swapping.
- **Pipeline as flexbox with CSS arrows** — Not an image. Responsive: horizontal on desktop, vertical stack on mobile. Each stage colored by zone.
- **Architect review as vertical timeline** — The B+ to A journey is told as a timeline with dot markers, finding/fix pairs in side-by-side cards, and final blockquotes. More engaging than a table.
- **Agent cards as responsive grid** — 20 agents displayed as cards with monospace name in accent color and italic quote. auto-fill grid adapts from 1 to 3 columns.
- **Obama medal image with graceful fallback** — img tag with onerror handler that hides the broken image and shows a placeholder div. No broken image icon.
- **Fade-in on scroll via IntersectionObserver** — Subtle, CSS-transition-based. Fallback for browsers without IO just shows everything.
- **Workflow steps as CSS counter circles** — No hardcoded numbers. HUMAN APPROVAL GATE labels styled in warning color.
- **Session links point to GitHub blob URLs** — Since the site is on GitHub Pages, session log links go to the GitHub blob view of the markdown files.
- **No external dependencies** — Zero CDN loads, zero web fonts, zero tracking scripts. Total CSS is ~12KB, JS is ~2KB. Well under the 100KB target.
