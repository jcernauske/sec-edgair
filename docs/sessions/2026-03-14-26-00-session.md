## Decisions Made
- build_company_financials() accepts facts and entity_mappings as parameters (list[dict]) for testability, matching the pattern from financial_facts_model. CLI reads from Iceberg, tests pass constructed data.
- Concept collision fallback sorts by (tier ASC, concept_frequency DESC) -- lowest tier number wins (tier 1 = best match), then most common concept breaks ties.
- companies_reporting computed per (business_term_id, fiscal_period) NOT per (business_term_id, fiscal_year, fiscal_period) -- per the spec, it answers "how many companies report this term quarterly/annually" not "how many reported it in FY2024."
- Used regular dicts with .setdefault() instead of defaultdict per the security hook constraint.
- SIC_TO_SECTOR hardcoded in config.py (18 SIC codes for 20 companies) rather than importing from entity_resolution -- simpler, no cross-module dependency.
