## Decisions Made
1. **No staging/approval gate** — Unlike entity resolution and tag normalization, the financial facts join is purely mechanical. Both upstream tables already went through human approval. Adding a gate here would be friction without value.
2. **Grain includes accession_number** — This means amendments create separate rows rather than updating in place. Deduplication to "latest value" is explicitly deferred to the consumable zone. This preserves full audit trail.
3. **Fiscal calendar from observed data** — Rather than computing period boundaries from fiscal_year_end rules, we extract actual (start_date, end_date) from what was filed. This handles fiscal year changes, short periods, and transition quarters correctly.
4. **Supersession by filed_date, not form type** — A 10-K/A supersedes a 10-K, but also a later 10-K can report the same fact. filed_date is the universal ordering.
5. **Unmapped concepts get explicit defaults** — tier=3, financial_statement="other", category="uncategorized" rather than nulls, so downstream can filter without null handling.
