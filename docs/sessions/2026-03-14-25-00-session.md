## Decisions Made
- **BT-049 (Sector) is not a CDE** -- it's a derived classification from SIC codes, not a core identifier critical for operations. It enables peer grouping but is not essential for data joins or audit trails.
- **BT-050 (Companies Reporting) is not a CDE** -- it's a computed aggregate for coverage signaling. Useful for consumers but not critical for cross-system operations.
- **Both new terms auto-approved** -- REQUIRE_HUMAN_APPROVAL is false in dev/demo mode. Both are project-specific terms that would normally require human approval.
- **EDA noted 8 sectors, not 6** -- the spec's "6 sectors" estimate in Section 5 was an undercount. The actual SIC-to-sector mapping produces 8 distinct sectors (Technology, Financials, Healthcare, Consumer Staples, Consumer Discretionary, Energy, Industrials, Communication Services).
- **All 8 DQ rules set to P0** -- the consumable table is a deterministic transformation. Any rule failure indicates a build bug, not a data quality issue, so all rules are blocking.
- **CONS-CF-006 uses GROUP BY validation** -- rather than joining to a pre-computed table, the rule validates companies_reporting against the actual COUNT(DISTINCT cik) within the same table. Self-contained validation.
